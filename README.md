## Pickle Trivia is ideal for knowledge enthusiasts and curious minds, offering a fun and interactive way to learn. Players can:

 - Explore 20+ diverse topics 
 - Choose their favorite category 
 - Receive instant feedback through vibrant color cues for each answer
 - Track their progress and view their total score at the end

## Usage 
- From the src under the app folder, `npm run build` to install dependencies, and then `npm run dev` to actually run the website in your localhost.
- Additionally, the github page works perfectly fine if you simply want to play the game and not clone the repo.

## Requirements
- Node v20
- Vite 5.0.12

### Installing Dependencies

From within the root directory:

```sh
npm run build
```
